- **Format**: JPG
- **Quality**: High-resolution, professional travel photography
- **File Size**: Optimized for web (under 500KB when possible)
- **Content**: Must accurately represent the location/service described in filename

### Copyright Requirements
- Recommended sources: Travel websites, blogs etc Unsplash, Pexels, Pixabay, or other royalty-free platforms

- **Location**: Save each real image in the same subfolder as its placeholder
